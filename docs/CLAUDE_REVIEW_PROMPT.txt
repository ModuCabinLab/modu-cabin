2. 공용 풍량 교집합, 충돌 시 적용 차단, 프로필/좌석/일시 요청의 분리, 다음 탑승의 초기화 범위.
3. 주행 잠금, 적용 중 중복 조작, 오래된 비동기 결과, 수동 조작 우선, 실패/읽기 불가/불일치의 표시. 요청값을 확인된 현재값처럼 표시하는지 확인.
4. 밝은 새 화면의 정보 우선순위, 차량 형태의 인지성, 차종별 좌석 및 9인승 터치 영역, 키보드 접근성, 좁은 화면, 글자 크기와 대비. 우선 시연 UX 관점에서 평가하고 실제 차량 HMI 인증을 받은 것으로 보지 말 것.
5. Android WebView의 로컬 파일 허용 목록, 외부 이동, 권한, JavaScript bridge, SDK 통합에서 남은 검증.
6. 영상·README·APK·공개 소스가 같은 기능을 보여주는지, 실제 차량 연동이나 학습 AI로 오해하게 하는 표현이 있는지.
