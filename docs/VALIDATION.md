## 브라우저 및 규칙 엔진 회귀 검사

4~8석 일반 캐빈과 현대차 5개 구성의 좌석 수·열 배치·정원 전원 연결을 검사했습니다. 아이오닉 9의 7석(2+3+2)과 팰리세이드의 7석(2+2+3)을 구분하고, 팰리세이드 9인→아이오닉 5 전환 시 새 탑승으로 초기화하는지 확인했습니다. 좌석 선택·키보드 접근·3열 이동·주행/적용 중 변경 차단·모바일 9인승 화면도 검사했습니다.

Claude 검토 패치의 회귀 테스트 5개를 기존 코드에 적용해 먼저 실패하는 것을 확인한 뒤 구현을 반영했습니다. 비워진 열선 지원 좌석은 다음 제안 적용 시 0을 요청합니다. 성공 결과에는 실패 사유가 없고 불일치에는 다른 키 목록을 남깁니다. gateway 지원 범위를 조회하고 풍량 제한자·충돌 당사자를 표시합니다. 이는 실제 Pleos SDK 호출이 아닙니다.

브라우저에서는 빈 좌석 열선이 적용 전 1에서 확인 후 0으로 바뀌는 과정, 적용 표시의 변경·실패 시 해제, 미지원 안내 분리, 390/540px 요청 버튼 배치를 확인했습니다. 390px 수면 버튼의 스위치가 밀리는 문제는 줄바꿈으로 수정했습니다. SVG 요소는 도면과 함께 축소되므로 모든 터치 영역이 44px 이상이라고 주장하지 않습니다.

수동 조작·탑승 세션 변경 이후 이전 비동기 응답 무시, 이전 요청 종료가 새 요청의 잠금을 해제하지 않는지, 내부 요청값 대신 실제 가상 읽기값을 표시하는지도 검사했습니다.
